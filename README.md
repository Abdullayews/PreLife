## 🧭 What is this?

**PreLife** is a self-development platform in progress. The idea: instead of
five different apps for your diet, workouts, reading list and meditation
practice, PreLife gives you **one hub with dedicated modules** — each
focused, each speaking your language (Azerbaijani, English or Russian).

The web app lives at the repository root and is built with **Next.js 16
(App Router) + React 19 + Tailwind CSS 4**, fully localized with
**next-intl**. The message catalogs are generated by a build script
(`npm run messages`) that verifies key parity and ICU params across all
three locales — and fails on any mismatch.

## ✨ Modules

| Module | Focus | Route | Theme |
|---|---|---|---|
| 🏋️ **Gym** | Training plans, exercises, partner gyms | `/gym` | Ember on Bone |
| 🥗 **Diet** | Nutrition, recipes, collections | `/diet` | Golden Harvest |
| 🧘 **Meditation** | Sessions, programs, benefits | `/meditation` | Lavender Haze |
| 📚 **Library** | Collections, featured books, perks | `/library` | Paper & Teal |

Each module is a full premium page under `src/app/[locale]/<module>` —
switchable photo hero (BetterMe-style gallery: three frames per module,
liquid-glass arrow/dot controls, 7s auto-advance), marquee band, feature
grids, plans/sessions, member stories and a closing CTA — with its own
light/dark palette (`.pl-theme-*` in
`globals.css`) and content data in `src/lib/content/`. The public funnel
— `/welcome` (landing), `/home` (dashboard) and `/subscription` (plans)
— shares the `.pl-theme-welcome` shell palette. Every palette is applied
as a **class** (never an inline style — inline styles outrank the `.dark`
overrides and would freeze a page in light mode), and each has a dark
variant: hero photo scrims and hero ink come from `--hero-*` /
`--on-hero-*` tokens, so the whole page re-tints when the nav's theme
toggle flips `.dark` on `<html>` — the `/welcome` landing opens with the
same full-bleed photo-hero scale as the module pages. The first visit
follows the OS appearance (`prefers-color-scheme`); a manual toggle is
persisted in `localStorage` and always wins afterwards. Native UI
(scrollbars, form controls) follows the active mode via `color-scheme`,
and the "Get started" band stays ink-dark in both modes via
`--contrast-*` tokens. One glass-pill nav
travels across the whole site: it starts full-width at the top of the
page and morphs — 0.45s Apple curve — into the smaller floating pill
(h-20 → h-16) once the page scrolls, picking up the current module's
accent automatically. The glass is painted
on a pseudo-element, so "transparent website" browser mods cannot strip
it.

## 🛠️ Tech stack

| Layer | Tools |
|---|---|
| Framework | Next.js 16.4 (App Router) · React 19.3 · TypeScript 6 |
| UI | Tailwind CSS 4 · shadcn-style components · Lucide icons · Geist + Montserrat · dark mode |
| i18n | next-intl — `az` / `en` / `ru` message catalogs + build/parity script |
| Quality | ESLint 10 |
| Runtime | Node ≥ 24 |

## 📁 Repository structure

```
PreLife/
├── messages/            # az.json · en.json · ru.json (generated — see scripts/)
├── public/              # static assets (banner, logo, robots)
├── scripts/             # message sources + build/parity script + push helper
├── src/
│   ├── app/[locale]/    # localized routes: welcome · home · gym · diet · library · meditation · subscription · ui
│   ├── components/      # site nav + theme toggle + explore strip + shells (+ shadcn-style ui kit)
│   ├── i18n/            # routing & request config
│   ├── lib/content/     # per-module page content (plans, exercises, stories…)
│   └── proxy.ts         # next-intl middleware (locale routing)
├── next.config.ts
└── package.json
```

## 🚀 Getting started

```bash
git clone https://github.com/Abdullayews/PreLife.git
cd PreLife

npm install
npm run dev          # → http://localhost:3000
```

Switch languages with the built-in language switcher — routes are
locale-prefixed (`/az`, `/en`, `/ru`).

## 📦 Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | dev server |
| `npm run build` | production build |
| `npm start` | run the production build |
| `npm run lint` | ESLint |
| `npm run messages` | verify parity + rebuild the three message catalogs |

## ☁️ Deployment

The site auto-deploys to **Render** from `main` — every push to `main`
triggers a fresh build (`npm ci && npm run build`) and goes live at
https://prelife.onrender.com.
